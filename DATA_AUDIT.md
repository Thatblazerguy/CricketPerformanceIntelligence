# Cricsheet Data Audit

## 2023 ICC Cricket World Cup reconciliation

- Found **39 of the 48** expected 2023 ICC Men's Cricket World Cup ODI matches in the local Cricsheet archive. ICC confirms the 48-match tournament size in its [official announcement](https://www.icc-cricket.com/news/prize-money-announced-for-icc-mens-cricket-world-cup-2023). The nine absent source IDs are `1384394`, `1384400`, `1384404`, `1384407`, `1384413`, `1384421`, `1384425`, `1384430`, and `1384433`; no corresponding local JSON files exist. These are distinct from 2023 qualifier and qualifier play-off competitions.
- The last successful archive/database reconciliation showed all 23,241 source match IDs imported and no missing source IDs. The live match-list API now returns all **39** exact-event ODI records filtered by exact competition `ICC Cricket World Cup`, format ODI, and year 2023. No download/reimport was indicated by the reconciliation.
- These files use format `ODI`, Cricsheet season `2023/24`, and the 2023 match dates; competition filter text should be `ICC Cricket World Cup`. Full source IDs, dates, teams and venues are in [the targeted World Cup audit](data/reports/world_cup_2023_audit.md).
- The official site describes its 23,241-match JSON download as the full released collection, matching the local snapshot count. The nine missing IDs were not available in that collection, and the official page did not expose individual-match downloads for them during this audit. API validation returned 39 matches, and opening one returned 2 innings and 569 deliveries, including extras and wickets (65.0 ms in a single local TestClient request). The list request took 73.6 ms. These are single-run timings, not a benchmark.

## Reference CSV inputs

Inspected and copied the user-provided reference CSVs into `data/reference/cricsheet/`: `names.csv` (7,551 rows; identifier/name), `people.csv` (18,698 rows; stable identifier, name, unique_name and external provider keys), `venue_names.csv` (297 rows; venue identifier/name), and `venues.csv` (591 rows; identifier, name, unique_name and Cricinfo keys). These are reference data, not instructions. Applied the ID-only importer; it added 4,737 player aliases, 15,088 sourced unique-name attributes and 279 venue aliases, and standardized 26 venue names. 3,380 people IDs did not map to a player already present in this Cricsheet match collection; no name-based player merges were attempted. A follow-up identity pass merged 32 duplicate venue rows strictly by Cricsheet venue identifier and relinked 1,296 matches, preserving prior source venue names as aliases. Future ingestion now resolves venues by registry ID first.
